# ODU logos

Put official ODU logo files here. Do not redraw, recolor or rearrange them.

1. Download from the ODU brand toolkit: https://www.odu.edu/university-communications/brand-toolkit/current-logos
   (the Tier 1 versions are in ODU's Bynder library and need a MIDAS ID).
2. Use PNG or SVG files for the web. EPS and 300 dpi files are for print.
3. Suggested names: `odu-signature-2color.png` (light mode) and `odu-signature-white.png` (dark mode).
4. Before launch, check the University Identity Standards for how a lab may show the ODU logo next to its own (Katie to confirm with University Communications).
